## 本轮确定缺陷与修复

主要实现：`luarules/gadgets/game_roguelike_weapon_effects.lua`。测试驱动真实 Gadget，Spring 为模拟接口。

| ID | 原问题及原因 | 修复与验证 |
|---|---|---|
| F01 | `splitProjectile` 与 `spawnChild` 各扣一次预算；2份预算实际只生成1发 | 只由实际生成端扣一次；模拟2份预算产生2发 |
| F02 | 二代飞行分裂没有 originX/Z，距离一直按当前位置减当前位置算成0 | 子弹记录自身出生位置；两代模拟产生2+4发 |
| F03 | 陨石到期先出队，后检查玩家容量；容量满就丢失攻击 | 容量不足保留队列；释放后下一帧生成 |
| F04 | 陨石生成前不检查全局容量，生成后又被登记器删除 | 提前检查全局容量并排队；模拟全局满时不调用生成 |
| F05 | SpawnProjectile 返回 nil 也已出队 | 仅成功登记后出队；模拟失败后重试成功 |
| F06 | 通用武器只是登记附加效果，登记预算满却删除原始主弹 | 跟踪失败时保留主弹，跳过本次额外效果并增加拒绝计数 |
| F07 | 火区3个上限用所有区域状态计数，3个余震会封锁第1个火区 | 火区数与总区域数分别计算；保留总上限 |
| F08 | 未填 trigger 的 onHit 效果也能在 onKill 执行；致死回调可能提前消耗事件 | 缺省只匹配 onHit，显式 onKill 仍一次触发 |
| F09 | UnitDamaged 给的是结算后伤害，再 AddUnitDamage 会重复走角色/商店倍率 | 统一用原 WeaponDef 基础伤害乘弹丸自身倍率作为派生基数；模拟200最终伤害/100基础伤害产生35余震基数，而非70 |
| F10 | 房间覆盖层隐藏 document 后，KeyPress/鼠标处理只检查设置框，可能暗中响应按键 | `optionsDialogOpen` 统一包含 lobbyHidden 和全局隐藏UI；源码/语法检查通过，实机待验 |

F09 为修复重复计算，数值口径在 Balance 最新审计节说明。未调整全局敌人 HP 曲线、升级价格或角色成长系数。
