BAR PVE Friend Launcher

1. Install the official Beyond All Reason client and start it once. Exit BAR before switching versions.
2. Extract this folder and run BAR-Custom-Test-Launcher.exe.
3. Select the BAR client's data\chobby_config.json if the launcher does not find it.
4. Choose PVE and click Update and Join PVE. The launcher reads the server version from GitHub and downloads the matching game package from GitHub Releases.

The first PVE download is about 2 GB. Keep the official BAR launcher installed; this package adds BAR PVE alongside it. The development mode requires selecting a local BAR-PVE source tree and is optional.

Lobby: frp-tag.com:53984 (TCP)
The game server sends the game connection address and UDP port through the lobby.
